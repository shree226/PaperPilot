# Claim Inventory
Create a table with these columns:
- Claim or result
- Supporting evidence
- Source filename
- Page if available in metadata
- Confidence
- Missing context

# Strong Evidence
- List claims with direct and specific document support.

# Weak or Unsupported Evidence
- List claims that appear incomplete, ambiguous, or contradicted.

# Verification Needed
- Identify statements that cannot be resolved from the indexed documents.
